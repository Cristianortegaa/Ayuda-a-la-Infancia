# 🌟 Ayuda a la Infancia 116-111

Página web informativa “Ayuda a la Infancia 116-111” desarrollada con **HTML5** y **CSS3**.  
Incluye encabezado, menú de navegación, secciones con imágenes y texto, y pie institucional.  
Proyecto enfocado en practicar **maquetación**, **diseño visual** y **estructura semántica** sin frameworks.

---

## 🧩 Tecnologías utilizadas
- HTML5  
- CSS3
